Removed deprecated etcd API v2 support and renamed-kwarg compatibility shims in ``salt.utils.etcd_util``:

- The ``EtcdClient`` (v2) class was removed. ``get_conn`` now always returns ``EtcdClientV3``; set ``etcd.require_v2: False`` (or remove the key) in your etcd profile.
- Setting ``etcd.require_v2: True`` now raises a ``CommandExecutionError`` instead of a deprecation warning.
- The ``index``/``waitIndex`` kwargs on watch methods were removed; use ``start_revision``.
- The ``recursive`` kwarg was removed; use ``recurse``.
