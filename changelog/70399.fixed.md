Fix "Master did not return a session key for pillar request" on master clusters with ``cluster_isolated_filesystem: True`` behind an L4 load balancer. Session keys are now derived via HKDF-SHA256 with ``cluster.pem`` as IKM and ``cluster_aes`` as HKDF salt, so every peer master computes the same per-minion key without replicating ``cachedir/sessions/<minion>``, while no minion can derive another minion's session key (``cluster.pem`` is master-only, distributed via join-reply and never sent to minions). Rotation stays in lockstep with ``cluster_aes``. Standalone masters and shared-filesystem clusters keep the existing random-file behavior.
