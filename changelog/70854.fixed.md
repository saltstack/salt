Bumped relenv from 0.22.27 to 0.23.2, which adds native Windows arm64 build support (0.23.0), updates krb5 to 1.22.3 for CVE fixes and bumps bundled Python 3.11 to 3.11.18 along with intermediate expat and sqlite updates (0.23.1), and updates libffi to 3.8.1 (0.23.2). Pinned at 0.23.2 rather than the newer 0.24.0 because 0.24.0's `relenv relocate` change (saltstack/relenv#352) exposes a pyzmq RPATH-extension path that the x86_64 kernel ELF loader rejects at import time with `ELF load command address/offset not properly aligned`; 0.23.2 is the last release before that relocate change and ships the same CPython point releases as 0.24.0. Bumped the CI `python_version` pin to 3.11.18 to match (regenerated `.github/workflows/{ci,nightly,scheduled,staging}.yml` from `cicd/shared-gh-workflows-context.yml`), and aligned the onedir build matrix in `tools/ci.py` with the CPython point releases relenv 0.23.2 ships (3.10.22 / 3.11.18 / 3.12.16 / 3.13.18); the previously pinned 3.10.21 / 3.11.16 / 3.12.14 / 3.13.15 were pulled from relenv's fetch mirrors.
