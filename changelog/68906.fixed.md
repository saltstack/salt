Fixed gitfs, git_pillar and winrepo ignoring proxy configuration. The new
``gitfs_proxy``, ``git_pillar_proxy`` and ``winrepo_proxy`` options (also
settable per remote as ``proxy``) are enforced as ``http.proxy`` in each
cached repository's git config, and the pygit2 provider now enables proxy
lookup when fetching, which it previously never did. Backport of the proxy
support added in 3008.0.
