Fix ``LocalClient.pub`` / ``pub_async`` on clustered masters: when Raft is still forming the receiver returns ``{"enc": "clear", "load": {"ret": False, "cluster_retry": True}}`` with no ``jid`` key, which previously crashed the client with ``KeyError: 'jid'`` (wrapped by ``cmd_async`` as the opaque ``SaltClientError: 'jid'``). The client now detects the ``cluster_retry`` sentinel on the return and raises a plain ``SaltClientError`` with an actionable message telling the operator the cluster is still forming and to retry.
