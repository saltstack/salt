Route resource-grain writes in the master's ``_register_resources`` chunk handler through a new ``Cache.store_many`` batch API (native ``put_many`` fast path on ``mmap_cache``, per-item fallback for other drivers). Previously each chunk serialised ~N ``cache.store`` calls — up to ~50s on cold caches — exceeding the minion's ``return_retry_timer`` window and triggering a reconnect-drops-reply retry cascade that could stall minion registration past ``resource_register_chunk_retries``.
