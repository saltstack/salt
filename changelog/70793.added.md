``whitelist_modules`` and ``whitelist_state_modules`` now accept
function-scoped entries of the form ``module.func`` in addition to the
existing bare ``module`` entries.  A dotted entry narrows the allowed
set to just the listed functions of that module; a bare entry still
allows every public function.  When both shapes appear for the same
module the dotted entries win -- ``[cmd, cmd.run]`` allows only
``cmd.run``, so tightening an existing whitelist does not require
removing the broader bare entry.
