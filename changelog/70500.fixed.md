Recover master-topology outbound links after a REQ-channel wedge.
`PeerMasterLink._handle_send_fault` now tears down the channel and
marks the link `DEGRADED` on `SaltReqTimeoutError`; a periodic
sweeper in `link_manager` re-handshakes degraded links. Mirrors the
same "rebuild on fault" pattern already used in `connect()`'s
handshake retry loop. `topology.peers` surfaces per-link fault
counters so operators see "attached per key, dead per forwards"
without grep.
