Cluster AES key rotation now propagates to peers when ``cluster_isolated_filesystem: True``. The rotating master embeds the freshly-generated cluster_aes encrypted per-peer in the ``rotate_cluster_aes_key`` event so receivers can install it on their local ``cluster_pki_dir/.aes`` instead of re-reading an unchanged file. Also removes the stale ``.dfn`` dropfile after a ``publish_session`` rotation to stop the double-rotation per cycle on the same master.
