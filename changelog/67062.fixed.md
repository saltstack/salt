Fixed a confusing failure when ``pki_dir`` (or another verified directory) is
already owned by a different user than the one Salt is configured to run as
and the current process can't fix the ownership itself (e.g. it isn't
running as root). Previously this only logged a vague
``Unable to securely set the permissions`` message and continued, surfacing
an unrelated-looking ``PermissionError`` much later during key generation.
It now raises a clear, actionable error immediately, naming the current
owner, the configured user, and the ``chown`` command needed to fix it.
