Fixed `pkg.list_upgrades` on yum/dnf systems not honoring extra kwargs such as `exclude='kernel*'` or `security=True`. The function now passes `get_extra_options=True` to `_get_options`, matching the behavior of `pkg.upgrade`. Previously `state.test=True` reports from `pkg.uptodate` could diverge from the real run because the preview path used `list_upgrades` while the apply path used `upgrade`.
