Fix a deadlock where three or more simultaneous ``state.*`` runs using ``queue=<int>`` on one minion waited on each other forever, by treating a running job that is itself waiting in the queue as blocking only younger JIDs. Also fixes the same deadlock on the ``salt-call --local`` path, stops ``Minion.__init__`` from deleting a live ``queue.lock`` when per-job subprocesses re-run initialisation on multiprocessing spawn-start platforms, restores SIGKILL recovery across every master in a multimaster configuration, isolates ``queue.lock`` per proxy so two ``salt-proxy`` daemons sharing a cachedir do not collide, adds a PID liveness check so a respawn cannot delete a lock held by an orphan child, and runs the same cleanup at ``salt-call`` startup so a SIGKILLed invocation does not leave a lock behind.
