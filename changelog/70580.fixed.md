Fix a deadlock where three or more simultaneous ``state.*`` runs using ``queue=<int>`` on one minion waited on each other forever, by treating a running job that is itself waiting in the queue as blocking only younger JIDs. Also stops ``Minion.__init__`` from deleting a live ``queue.lock`` when per-job subprocesses re-run initialisation on multiprocessing spawn-start platforms, restores SIGKILL recovery across every master in a multimaster configuration, isolates ``queue.lock`` per proxy so two ``salt-proxy`` daemons sharing a cachedir do not collide, records the holder's PID in the lock file so cleanup can skip a live holder (with a process-start-time check to defeat PID reuse), stops ``wait_lock``'s release from raising ``FileNotFoundError`` when the file was removed out from under the holder, and runs the same cleanup at ``salt-call`` startup so a SIGKILLed invocation does not leave a lock behind.
