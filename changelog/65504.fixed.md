Fixed `salt '*' config.items` and similar minion jobs crashing with `AttributeError: 'NoneType' object has no attribute '__iter__'` when the returned payload contains a `NamedLoaderContext` whose underlying value is `None`. The mapping-typed loader dunders (`__opts__`, `__context__`, `__pillar__`, `__grains__`) now default to `{}` off-context so the `MutableMapping` contract is honored and `salt.payload.dumps` can encode them cleanly.
