Removed several deprecated APIs that reached their Potassium (3009.0) removal deadline:

- ``salt.utils.openstack.neutron`` module (unused OpenStack Neutron helper).
- ``salt.transport.client`` and ``salt.transport.server`` shim modules; use ``salt.channel.client`` and ``salt.channel.server`` directly.
- ``salt.features.Features.get()``; check the ``features`` key on the configuration dictionary instead.
- ``salt.utils.versions.StrictVersion``; use ``salt.utils.versions.Version`` instead.
- ``salt.utils.zeromq.ip_bracket()``; use ``salt.utils.network.ip_bracket()``.
- The ``file.shortcut`` state; use ``shortcut.present`` instead.
