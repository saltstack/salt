Declared the OS tools (`coreutils`, `grep`, `findutils`, `getent`, `awk`, `sed`, `systemd`, `openssl`) used by the `salt` and `salt-minion` RPM `%pre`/`%post`/`%preun`/`%postun`/`%posttrans` scriptlets as scriptlet-scoped `Requires`, so package managers can correctly resolve install ordering instead of silently failing on minimal or air-gapped installs.
