Removed the deprecated M2Crypto-based X.509 execution and state modules.
The cryptography-based `x509_v2` modules are now the only implementation
exposed as `x509`; `features:x509_v2` no longer selects the old modules.

Removed compatibility with legacy arguments. See the
[migration guide](https://docs.saltproject.io/en/master/ref/modules/all/salt.modules.x509_v2.html#x509-migration-3009)
for the required changes and new defaults.
