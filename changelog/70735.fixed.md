Quiet cluster-bringup ``[ERROR]`` noise on non-pillar RPC paths. Follow-up
to #70727: the ``cluster_retry`` deadline-exceeded message from
``_crypted_transfer`` is now detected by the same
``_is_cluster_not_ready_message`` helper, and ``SyndicManager._connect_syndic``
demotes the "Error while bringing up syndic" ERROR to a single INFO retry
notice when the underlying ``AuthenticationError`` carries the
cluster-not-ready sentinel. Non-cluster errors keep the existing ERROR path.
