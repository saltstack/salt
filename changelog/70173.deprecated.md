Standardized the filesystem pass parameter across the ``mount`` state and execution modules. The ``pass_fsck`` and `fs_passno` arguments have been deprecated in favor of a unified `pass_num` argument to prevent Python keyword conflicts and improve consistency. Additionally, the output dictionary for ``mount.fstab`` (and related functions) now includes ``pass_num``. The legacy arguments and the legacy ``pass`` output key will be removed in Salt 3011. Users should update their SLS files and Jinja templates to use ``pass_num``.
