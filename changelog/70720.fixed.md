Minion no longer keeps per-resource grain dicts resident in memory by default; set ``resource_grains_cache_in_memory: True`` to restore the old behavior for grain-target-heavy workloads.
Minion chunks the resource register RPC (default 10 000 resources per chunk) so large resource sets no longer time out the single-RPC retry-timer, losing partial register state. Backward-compatible with older masters.
