Bumped GitPython from `==3.1.50` to `==3.1.60` across every static lock file under `requirements/static/{ci,pkg}/py3.*/`, and raised the corresponding lower bounds in `requirements/base.txt` and `requirements/static/ci/{common,darwin}.txt` from `>=3.1.50` to `>=3.1.59` so subsequent pip-compile runs can't drift back into the vulnerable range. Fixes CVE-2026-78676 (GHSA-284h-m62q-gf8w) — GitPython re-serialization corrupts a dormant multi-line quoted config value into an executable directive (e.g. `core.hooksPath`), enabling RCE via crafted config files.
