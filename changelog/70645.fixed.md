Extend the stale-CONFIG short-circuit from `MembershipStateMachine.apply` to the three sibling Raft state machines (`RingConfigStateMachine`, `RingRegistryStateMachine`, `RoutingStateMachine`) which shared the same unconditional `self._version = index` pattern. A stale entry re-delivered via log truncation or recovery replay no longer silently overwrites ring policy, ring registry, or routing-table state. The existing `_version` field already round-trips through each SM's snapshot envelope, so the gate survives snapshot install.
