Flip the `topology_pub_ack_consumer` default from False to True. CLI (`LocalClient.get_iter_returns`) now exits its wait loop as soon as every peer that acknowledged a flooded publish has reported local-collection completion, instead of always waiting out `--timeout`. Mixed-deployment fallback is preserved: a peer running without emission still falls through the generic `--timeout` branch. Set `topology_pub_ack_consumer: False` in master opts to restore the pre-RFC syndic-style silent-inference behavior. See RFC `doc/topics/master-topology/rfc-pub-ack-complete.md`, Phase 3.
