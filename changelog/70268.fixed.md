Point the pkg-test SaltPkgInstall fixture at Canonical's Azure Ubuntu mirror on Ubuntu 24.04. The ``ubuntu-24.04`` CI container's baked-in ``archive.ubuntu.com`` / ``security.ubuntu.com`` sources fetch at ~30 kB/s from GitHub-hosted runners, blowing past the 240 s subprocess timeout wrapping every ``apt install`` and tearing every Ubuntu 24.04 install / upgrade / downgrade matrix with ``FactoryTimeout``. The Azure mirror responds in under 1 s from the same runner and drops ``apt-get update`` to ~2 s.
