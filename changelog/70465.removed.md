Removed Potassium (3009.0) deprecations in ``salt.states.x509_v2`` and ``salt.client.ssh.wrapper.x509_v2`` to match ``salt.modules.x509_v2``:

- ``algorithm`` kwarg (certificate/CSR creation) — use ``digest``.
- ``text`` kwarg (CRL creation) — removed.
- ``bits`` kwarg (private-key creation) — use ``keysize``.
- Old-style ``{key: [dict, ...]}`` wrapping of revoked entries in CRL state — pass a plain list of dicts.
- Top-level ``reason`` key on revoked entries — put it under ``extensions:CRLReason``.
- Long-form OpenSSL name attributes and extensions in signing policies — use short-name attributes.
- Default of ``days_valid`` for certificates: ``365`` → ``30``.
- Default of ``days_valid`` for CRLs: ``100`` → ``7``.
- Default of ``days_remaining`` for CRLs: updated to match the new ``days_valid`` default.
