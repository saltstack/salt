``pillar_mask_output`` now defaults to ``False``: pillar functions return real values regardless of ``unmask``, and received pillar containers show real values in ``repr()`` and ``str()``. Set it to ``True`` to enable context-controlled masking and use ``unmask=True`` to expose a function result. The general output safety net and states with ``no_log: True`` continue to redact independently of this option.
