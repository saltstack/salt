``pillar_mask_output`` is now a feature flag that defaults to ``False``. While it is off, pillar masking is disabled: ``pillar.get``, ``pillar.item``, ``pillar.items`` and ``pillar.ext`` return real values and ``unmask`` has no effect, and the pillar is not redacted in ``repr()`` or the output safety net. Set ``pillar_mask_output: True`` to mask it, and pass ``unmask=True`` to unmask a single call. States with ``no_log: True`` stay redacted either way.
