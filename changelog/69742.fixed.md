Fixed ``salt-ssh`` failing to spawn its Virtual Terminal on macOS 26 (Tahoe). On this OS the kernel returns ``ENOTTY`` for the ``TIOCSWINSZ`` ioctl on a pty slave, which aborted ``Terminal`` spawn inside ``preexec_fn`` with a generic "Exception occurred in preexec_fn." error and made every ``salt-ssh`` command unusable. ``salt.utils.vt.setwinsize``/``getwinsize`` now prefer Python 3.11+'s ``termios.tcsetwinsize``/``tcgetwinsize`` (which take a different code path and work on macOS 26) and tolerate ``ENOTTY`` so the non-critical window-size call no longer breaks command execution.
