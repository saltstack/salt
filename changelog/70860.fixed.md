``test.cross_test``, ``test.try_``, ``mine.send``, ``mine.update`` and
``snapper.run`` now dispatch their caller-supplied function name via
the whitelist-gated loader (``__wire_salt__``) instead of the
unfiltered inner ``__salt__``.  ``whitelist_modules`` now applies to
the target function as well as to the dispatcher itself.  The
``test.cross_test_safe`` wrapper added in #70795 is removed; its
behaviour is now the default on ``test.cross_test``.
