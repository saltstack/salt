Code running inside a job (execution modules, states) that calls ``pillar.get``, ``pillar.items``, ``pillar.item`` or ``pillar.ext`` through ``__salt__`` without ``unmask`` now receives real values instead of the ``**********`` placeholder. Pillar functions run directly from the CLI or API, and repr/log output of pillar data, stay masked. Functions that only display pillar data should pass ``unmask=False``.
