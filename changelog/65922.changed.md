Enhanced the ``ps`` beacon to return the ``username`` and ``create_time`` of
each matched process and to support filtering by username. Each ``processes``
entry is now a list of single-key dicts with a required ``status`` key and an
optional ``username`` key. The legacy
``processes: {<name>: <status>}`` flat-dict form is still accepted and emits
a deprecation warning; it will be removed in a future release. See the
``salt.beacons.ps`` module docstring for the new config shape.
