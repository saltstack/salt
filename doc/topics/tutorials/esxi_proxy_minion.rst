=================
ESXi Proxy Minion
=================

.. deprecated:: 3009.0

    The built-in ``salt.modules.vsphere`` execution module and the ESXi Proxy
    Minion integration that depended on it were removed in Salt 3009.0
    (Potassium) after their deprecation period expired. The tutorial that
    previously lived at this URL described a workflow that no longer works
    with a stock Salt 3009.0 or later install.

    For VMware functionality on Salt 3009 and later, use the
    `saltext.vmware extension
    <https://github.com/saltstack/salt-ext-modules-vmware>`_, available on
    PyPI as ``saltext.vmware``. Consult that project's documentation for
    installation and migration guidance.

    See also the general `Salt Extensions
    <https://salt-extensions.github.io/>`_ project for other out-of-tree
    extension modules.
